# Quickstart: 插件发版、验签与安装验证指南

## 1. 开发者本地发版与签名自测

```bash
# 1. 生成或载入 Ed25519 密钥对
./scripts/dev-release.sh keygen

# 2. 本地全量打包、压缩并签名
./scripts/dev-release.sh pack 1.0.0

# 3. 密码学自检
./scripts/dev-release.sh verify 1.0.0
```

---

## 2. 宿主端 UI 交互验证

1. 启动 TTZip.app；
2. 导航至「插件中心」->「插件商店」；
3. 点击「获取安装」，观察流式下载进度环与速度指标；
4. 确认 SHA-256 与 Ed25519 验签通过，状态自动流转为「已安装」；
5. 检查左侧边栏是否已响应式出现「飞书知识库」工作区；
6. 点击「卸载」，检查左侧边栏是否已即时消失。
